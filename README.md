# EDA-for-Salary-Prediction

This project is focuses on understanding and solving a business problem using exploratory data analysis (EDA) and basic data science techniques.

## 📌 Objective

The main objective of this project is to predict employee salary based on various industry features. The assignment walks through all steps of the data science life cycle, from business understanding to data acquisition, preparation, and analysis.

---

## 🧠 1. Business Understanding

* **Problem Statement:** Predict employee salaries using relevant features from job listings.
* **Required Data:** Dataset with salary details, job roles, industry sector, and company attributes.
* **Source:** Publicly available dataset from GitHub.
* **Analytics Task:** Exploratory Data Analysis (EDA) and initial preprocessing.

---

## 📥 2. Data Acquisition

* Dataset used: [glassdoor\_jobs.csv](https://raw.githubusercontent.com/goodluck08/practice_dataset/main/glassdoor_jobs.csv)
* Contains 20+ features and over 10,000 rows.
* Data loaded and verified using `pandas`.

---

## 🧹 3. Data Preparation

* Checked and removed:

  * **Duplicate entries**
  * **Missing values**
  * **Irrelevant or redundant columns** (e.g., unnamed columns)

* Performed:

  * Type checking
  * Initial insights on data types and descriptive statistics
